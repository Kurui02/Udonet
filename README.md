# UdoNET - Módulo 3: Publicaciones, Hilos y Buscador

Plataforma universitaria UdoNET desarrollada con Next.js (App Router), Tailwind CSS y Supabase.

## 🚀 Inicio Rápido

1. Instalar dependencias:
```bash
npm install
```

2. Iniciar el servidor de desarrollo:
```bash
npm run dev
```

3. Abrir [http://localhost:3000](http://localhost:3000) en el navegador.

---

## 📖 Guía Oficial para Integradores

Consulta la [Guía de Integración del Módulo 3 (INTEGRATION.md)](src/modules/module_3/INTEGRATION.md) para revisar:
* API Pública (`@/modules/module_3/exports`).
* Integración oficial desacoplada componente por componente (`CreatePostProvider`, `SearchBox`, `PostList`, `ThreadView`).
* Puntos de conexión pendientes con **Módulo 1** (Auth Real) y **Módulo 5** (Moderación y Reportes).
* Integración activa con **Módulo 2** (Comunidades) y **Módulo 4** (Votos y Reputación).
* Justificación académica de las **Estructuras de Datos** (Árbol N-ario + Map, Trie, Hash Sets).
